# AI Usage Log - Week 06

## Tujuan Penggunaan AI

AI digunakan sebagai alat bantu dalam proses pengembangan website KursusKu pada Week 06.

## Penggunaan AI

1. Membantu membuat dan memperbaiki form pendaftaran kursus.
2. Membantu menambahkan input nomor telepon dan program studi.
3. Membantu membuat halaman ringkasan hasil pendaftaran.
4. Membantu membuat halaman history dummy pendaftaran.
5. Membantu menyusun test matrix untuk pengujian form.
6. Membantu memperbaiki tampilan navigasi dan CSS agar lebih rapi.
7. Membantu memberikan saran struktur kode PHP dan HTML.

## Bagian yang Dikerjakan Sendiri

Kode kemudian diperiksa, disesuaikan, dijalankan, dan diuji kembali menggunakan Laragon serta browser.

## Hasil

Fitur Week 06 berhasil dibuat dan diuji, meliputi:

- Form pendaftaran lengkap
- Ringkasan data peserta
- Checkbox minat belajar
- History dummy
- Test matrix
- Dokumentasi penggunaan AI

## Kesimpulan

AI digunakan sebagai alat bantu selama proses pengembangan. Hasil dari bantuan AI tetap diperiksa dan disesuaikan dengan kebutuhan project KursusKu.
